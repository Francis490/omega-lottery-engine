Privacy Policy - Omega Trinity Engine

Ultimo aggiornamento: Ottobre 2026

1. Raccolta Dati

Questo bot non raccoglie, non memorizza e non condivide alcun dato personale degli utenti (come nomi, numeri di telefono o cronologia delle chat). L'unico identificativo utilizzato è il Chat ID, necessario esclusivamente per l'invio automatico delle notifiche.

2. Trattamento dei Dati

Tutte le analisi statistiche, i calcoli di Expected Value (EV) e la generazione dei numeri avvengono in modo anonimo. Il bot processa esclusivamente i dati pubblici delle estrazioni delle lotterie.

3. Servizi di Terze Parti

Il bot opera tramite l'infrastruttura di GitHub (per l'esecuzione del codice) e l'API di Telegram (per l'invio dei messaggi). Non utilizziamo tracker, cookie o sistemi pubblicitari.

4. Contatti

Per qualsiasi informazione o per richiedere la rimozione del proprio Chat ID dal sistema di notifiche, è possibile contattare l'amministratore del bot tramite il repository GitHub ufficiale.
